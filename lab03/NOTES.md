git diff сравнивает рабочую папку с индексом, два коммита и др.
git show выводит данные коммита и его изменения относительно родителя
git log выводит коммиты и данные их
git log -S... ищет в изменениях кода
git blame показывает для каждой строки коммит, который последним её изменил

чем git restore отличается от git restore --source=...
git restore - возвращает файл или все рабочую папку к версии последнего коммита
git restore --source= берет версию старого коммита в рабочую папку, может также взять отдельный файл
