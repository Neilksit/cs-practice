Рабочая папка - это директория, в которой хранятся все рабочие файлы

Индекс - это отслеживание файлов гитом для сохранения версии их

Коммит - это сохранение версии отслеживаемых файлов гитом



git - это контроль версий, а GitHub - хостинг, в котором хранятся все версии



git status - показывается состояние директории

git diff - показывает разницу между рабочим каталогом (рабочей директорией) и индексом

git diff --staged показывает разницу между индексом (staging area) и последним коммитом (HEAD)





Ветки: 

Ветка в Git — это указатель (ссылка) на конкретный коммит в истории проекта.

Когда вы делаете коммит в текущей ветке, указатель на эту ветку автоматически сдвигается вперёд — на новый коммит. 

Слияние — это процесс объединения изменений из одной ветки в другую. Обычно так делают, когда завершённая работа (например, новая функция) готова попасть в основную линию разработки.
